# Semantiniai Griaučiai komandinis darbas

Website project based on a Figma design. To learn how to work in a team and use Jira/GitHub

## Technologies used

- HTML
- CSS
- JavaScript
- VScode

## Work rules

- Github rules (TBA)
- One person works on one task.
    - First - check if task is not in progress.
    - Before starting - assign yourself to the task, so no other will do the same task.
- Naming conventions:
    - variable-name
    - id = PascalCase
    - class = camelCase
- Measures:
    - rem
    - px for media querries
- Work time:
    - 17:30 - 20:40
- Breaks:
    - 19:00 - 19:15
- HELP:
#####   - IF YOU DO NOT UNDERSTAND SOMETHING - REACH OUT TO YOUR FELLOW TEAMMATES!!! 
    
## File structure

- semantiniai-griauciai
    - styles (Folder for CSS styles)
        - normalize.css (CSS normalization)
        - general.css (Main styles: typography, color vars, common utility classes and so on...)
        - global.css (Global elements (Nav, Footer))
        - style.css ("Home" (index.html) page sections style)
        - about.css ("About" page stlye)
        - contact.css ("Contact" page style)
    - assets (Main folder for imported assets)
        - img (Folder for images)
        - fonts (Folder for fonts)
    - pages (Folder for pages further than index.html)
    - index.html (Yes.)
